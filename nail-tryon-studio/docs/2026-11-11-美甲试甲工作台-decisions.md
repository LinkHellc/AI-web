# 2026-11-11 美甲试甲工作台 · 结论与决策（decisions）

## 已确认

| 事项 | 结论 | 理由 / 依据 |
|---|---|---|
| 对标对象 | 豆包「美甲试甲工作台」 | 用户 12:22 更正「这个，发错了」，pixel-dot 作废 |
| 还原程度 | 以对标站为参考，可自行优化 | 用户：「可以根据你的审美和评估做得更好」 |
| 生图模型 | `gpt-image-2`（GPT-Image 2.0），可在 `.env` 改 | 用户指定；OpenAI 文档确认支持 edits |
| 生图方式 | `/v1/images/edits`，手照为 image 1、款式图为 image 2 | 编辑接口才能保留原手；多图参考是该模型能力 |
| 接口地址 / Key | 用户提供的 OpenAI 兼容中转，只存 `.env`（已 gitignore） | 安全；用户要求走配置 |
| 技术栈 | 零依赖 Node 22 + 原生 HTML/JS（**改自**最初说的 Next.js） | 用户在 Windows 本机跑，免 npm install、免构建；对标站本身是单页工具，不需要框架 |
| 存储 | 本地 `data/` 文件夹 + `history.json` | 单机工具，无需数据库 |

| 爆款来源 | 2026 小红书热门关键词汇总 + 时尚媒体 2026 趋势，人工整理 22 款 | 小红书需登录且出网受限，无法实时抓取；不编造热度数据 |
| 用户导入 | 本地服务端「我的款式库」（data/library） | 单机工具，导入后跨次使用；链接导入只允许公网图片 |
| 示例手图 | 用户提供的手图作为默认体验图 | 用户要求 |
| .env 优先级 | .env 非空值覆盖系统环境变量 | 用户电脑系统变量里有 OPENAI_BASE_URL，避免串配置 |

## 相对对标站的增强

- 款式库（12 款）+ 文字描述：没有款式图也能试
- 甲型 / 长度 / 质感 / 画质 / 尺寸可选；「两图齐全自动生成」可关
- 结果大图支持左右拖动对比上甲前后
- 试甲记录：查看、下载、恢复素材、删除
- 上传前压缩转 JPEG（兼容手机照片格式，降低 token 与超时）
- 模拟模式、访问口令、并发上限、中文错误提示、接口自检脚本

- 中转对 `gpt-image-2` 的支持（模型名、`size: auto`、`quality`）取决于中转实现。
- 对标站界面只拿到两张截图（结果页、生成中），上传初始态与移动端为自行设计。
