# AI 写真工作台

对标 pixel-dot.fly.dev 的「写真工作台」生成功能做的独立网页：保存模特 → 给模特换服装 → 选拍摄模式和动作（可批量）→ 一次出一组写真。
与美甲站（上级目录，端口 3000）完全独立，端口 **3001**，可以同时开。

## 启动

1. 确认上级目录 `D:\AI\20_美甲\.env` 已配好（美甲站能出图就行）。本工作台自动借用其中的 `OPENAI_API_KEY / OPENAI_BASE_URL / OPENAI_IMAGE_MODEL / HTTPS_PROXY`，不用再填一遍。
2. 双击 `start.bat`，浏览器打开 http://localhost:3001 。
3. 想单独换 Key 或端口：把 `.env.example` 复制为 `.env` 填写，本目录的值会覆盖上级。

检查接口：`npm run check`；测试（模拟模式，不扣费）：`npm test`。

## 功能

| 区块 | 说明 |
| --- | --- |
| 01 模特 | 每个模特存 1–4 张同一人的照片，反复使用；「模特」页可改名、删除 |
| 02 服装 | 最多 3 件单品图（上衣/下装/鞋包配饰），AI 换装；支持拖拽和 Ctrl+V 粘贴 |
| 03 拍摄模式 | 对镜 / 自拍 / 他拍 / 舞蹈定格 / AI 仿图（上传参考图复刻姿势构图） |
| 04 动作库 | 45 个动作分 8 类，可搜索；打开「批量模式」一次选最多 12 个，每个动作各出一组 |
| 05 场景风格 | 12 个模板：保持原背景、日系、韩系棚拍、胶片街拍、咖啡馆、海边日落、城市夜景、白底电商等 |
| 06 镜头 | 手动控制水平方位、俯仰角、距离（俯视/侧视示意图 + 6 个预设），自动转成镜头描述 |
| 07 渲染配置 | 锁定脸部/体型/服装/环境/道具；画质 快速/标准/专业；比例 2:3、1:1、3:2；分辨率 1K/2K/4K；每个动作 1–4 张 |
| 结果 | 批次进度、单张失败可重试；大图里可下载、「仿这张」、相同设置再来一张、删除；画廊按模特筛选 |

2K/4K 是 gpt-image-2 的自定义尺寸，中转不支持时自动降回 1K 并在详情里标注。

## 目录

- `server.js` 后端（零依赖 Node 22+）
- `lib/presets.js` 模式、动作、风格、镜头和提示词拼装（加动作/风格改这里）
- `lib/env.js` 读取上级 + 本目录 `.env`
- `public/` 前端
- `data/` 模特、输入图、作品与历史（不进 git）
